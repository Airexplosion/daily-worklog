# 每日工作梳理 · 首次安装说明

## 1. 下载

到 GitHub 发布页下载最新的 `DailyWorkLog_x.y.z_x64-setup.exe`。
GitHub 打不开或下载很慢的话，直接找发布人要安装包。

支持 Windows 10 / 11（64 位）。不支持 Win7 / 8 / XP。

## 2. 安装

双击安装包，一路"下一步"即可。

- 不需要管理员权限，装在你自己的用户目录下。
- 少数 Win10 电脑缺少系统组件 WebView2，安装包会自动联网补装，稍等一下即可。

### 弹出"Windows 已保护你的电脑"

软件暂时没有购买代码签名证书，所以 Windows 会提示这是"未知发布者"。处理方法：

1. 点提示里的 **更多信息**。
2. 点 **仍要运行**。

只有第一次会这样。

### 360 / 火绒 / 电脑管家拦截

软件会做三件安全软件比较敏感的事：注册截图快捷键、截取屏幕、设置开机自启。这三样都是软件正常功能需要的。

- 弹窗提示时选 **允许** 或 **信任此程序**。
- 安装包被直接隔离的话，在安全软件的"隔离区 / 恢复区"里找到 `DailyWorkLog`，恢复并加入信任。
- 开机自启被拦了，到安全软件的"启动项管理"里把"每日工作梳理"设为允许。

## 3. 第一次打开

软件会带你走 4 步设置：

1. 你的名字
2. AI 接口（用你自己申请的 API Key）
3. 你的写法
4. 快捷键和提醒

每一步以后都能在"设置"里改。

API Key 只存在你自己电脑上，地址是 `%APPDATA%\DailyWorkLog\settings.json`。

## 4. 平时怎么用

1. 做完一件事，按 **Ctrl + Alt + S**（可改），拖动鼠标框选。
2. 补一句话（截图里没有的人名、地点、原因写在这里），按回车。
3. 下班时软件会提醒你，点"生成今日总结"，然后复制，粘到微信。

## 5. 升级

软件发现新版本时会在顶部提示，点"去下载"下载新的安装包，直接运行覆盖安装即可。记录和设置都在 `%APPDATA%\DailyWorkLog\`，不会丢。

## 6. 数据在哪

`%APPDATA%\DailyWorkLog\`（设置页有"打开数据文件夹"按钮）：

| 文件 | 内容 |
|---|---|
| `data.json` | 所有记录和总结 |
| `settings.json` | 设置 |
| `shots\` | 截图原图（默认保留 90 天） |
| `backups\` | 每次启动自动备份，保留最近 7 份 |
| `logs\` | 运行日志，出问题时发给发布人 |

卸载软件不会删除这个文件夹。
