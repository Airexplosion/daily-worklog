# 截图升级：标注、复制、一条记录放多张图 · 设计文档

> 日期：2026-10-19
> 基于：《每日工作梳理》设计文档 v2（`2026-10-18-daily-worklog-design.md`，下称"主文档"）。本文只写这次新增和改动的部分，没提到的一律按主文档。
> 主文档 7.2 里留作 P1 的"＋ 再截一张，合到这条"，就是本文的一部分。
> 标【我的判断】的是写文档时自己定的，需求方没有逐条确认过。

## 1. 为什么要做

需求方提了两件事。

**第一件：平时截图就用这个软件。** 需求方平时截图大多是复制了发给同事、贴进文档，只偶尔想把截到的东西记进工作梳理。希望这个软件像常用的截图软件那样：

- 能画圈、画箭头、打马赛克；
- 框选完按回车就复制；
- 需要的时候才点"记录"，记进工作梳理。

这样只用一个截图工具、一个快捷键。

**第二件：一条记录放多张图。** 现在一条记录只能带一张截图，两种常见情况一张图装不下：

- **聊天记录**：一段对话一屏放不下，得往下翻好几屏。
- **几张不同的表格**：为同一件事要看好几张表。

这两种情况，要的都是"几张图合起来，记成一条"，而不是每张图各记一条。另外，有些图是电脑里已经存着的，比如微信里另存的图、别人发来的表格截图，这些也要能放进一条记录。

## 2. 目标 / 非目标 / 反目标

**目标**

- 框选完出现标注工具栏，有矩形、椭圆（画圈）、箭头、画笔、文字、马赛克，以及撤销。
- 框选完后图片的去向：
  - 回车 = 复制（默认，设置里可改成记录）；
  - Tab = 记录，进补一句小窗；
  - Ctrl+C = 复制；
  - Ctrl+S = 另存为文件；
  - Esc = 取消。
- 一条记录最多带 9 张图【我的判断】。
- 截完第一张以后，可以接着截第二张、第三张……全部算进同一条。
- 电脑里已有的图片，可以拖进来、粘贴进来或选文件加进来。
- AI 把这几张图**按顺序一起看**，只写**一条**工作事项、只打一组标签。
- 清单和历史里能看出这条有几张图，并能逐张翻看大图。

**非目标（这次不做）**

- 把截图"钉"在屏幕上（贴图）。
- 鼠标停在窗口上时自动框住整个窗口。
- 荧光笔、橡皮擦、编号气泡、文字识别（OCR）。
- 软件自己滚动窗口、拼成一整张长图。需求方确认过：自己往下翻、连着截几张就够用。另外长图发给 AI 时会被等比缩小，聊天文字反而看不清。
- 记录好以后再给这条加图、删图，或者改标注。想改，就删掉这条重新记【我的判断】。
- 给过去的日子补带图的记录。历史页不加图片入口【我的判断】。
- 在小窗里拖动调整图片顺序。
- PDF、Word 等非图片文件。

**反目标（做了也算失败）**

- **复制这条路变慢或变麻烦。** 热键 → 框选 → 回车，就得到剪贴板里的图，要和常用截图软件一样快。
- **只复制的截图被偷偷存下来或发给 AI。** 只复制、只另存的截图，不在数据目录里留文件，也不发给任何服务商。
- **记录变麻烦。** 记一条只比现在多按一个 Tab，不能再多。
- **几张图被拆成了几条记录。**
- **截第二张时按了 Esc 或出了错，前面已经截好的图丢了。**
- **界面文案、提示词、文档里出现具体举例。** 需求方要求过"所有举例都不要留"。

## 3. 约束

- 沿用主文档的技术栈和运行环境：Tauri 2，Rust 后端，原生 HTML/CSS/JS，不用打包工具，只支持 Win10/11。新增插件可以用 Tauri 官方插件（比如选文件、存文件的对话框）。
- 数据格式向后兼容。`Item.shots` 本来就是数组，老数据只是只有一张图，不需要迁移。
- 自动测试不能在用户的桌面上模拟鼠标和键盘。用 CDP 和 `DWL_DATA_DIR` 指向的测试数据目录，同主文档。
- 界面风格按主文档第 8 节（Win11 原生风）。

## 4. 已经定下的做法

### 4.1 框选完之后：标注工具栏（主文档 7.1 的改动）

**框选**

- 框选和现在一样：热键 → 冻结 → 拖框。
- 松开鼠标后**不再直接进补一句**：
  - 选框四边和四角出现拖动点，可以调整大小、拖动位置；
  - 选框下方出现工具栏。下方放不下就放在上方，上下都放不下就放在选框里面靠下【我的判断】。
- 画了第一笔标注后，选框就固定，不能再调大小【我的判断】。
- 右键 = 重新框选，已画的标注一起清掉。Esc = 取消整个截图，什么都不留。
- 顶部提示行在框选前和框选后分别是：
  - 框选前：`拖动鼠标框选　Esc 取消　右键 重选`
  - 框选后：`Enter 复制　Tab 记录　Ctrl+S 保存　Esc 取消`

**工具栏**

工具栏从左到右：

- 矩形、椭圆、箭头、画笔、文字、马赛克
- 分隔
- 撤销
- 分隔
- 保存…、记录、复制（主按钮，蓝色）
- ✕

各个工具：

- **矩形**：拖出一个框。
- **椭圆**：拖出一个椭圆，按住 Shift 是正圆。
- **箭头**：从起点拖到箭头指的地方。
- **画笔**：随手画。
- **文字**：在选框里点一下，就地打字，要能用中文输入法。正在打字时，回车只结束这段文字，不触发复制；点别处也结束这段文字。
- **马赛克**：拖一个框，框里的内容变成大像素块。必须是真正的像素块，不能用模糊，免得被还原。
- **撤销**：Ctrl+Z，一步一步往回退。

颜色和粗细：

- 选了某个工具后，工具栏下面出现第二行：6 种颜色（红、黄、绿、蓝、黑、白）和 3 档粗细【我的判断】。
- 文字工具的 3 档是字号，马赛克的 3 档是格子大小。
- 记住上次用的颜色和粗细，下次截图沿用【我的判断】。

**出来的图**

- 按**物理像素**生成，和现在一样。150% 缩放下，图的尺寸等于框住的物理像素，标注的位置、大小和屏幕上画的一致。
- 马赛克在原图像素上做。

**图片的去向**

| 操作 | 结果 |
|---|---|
| **复制** | 带标注的图放进剪贴板，截图结束。数据目录里**不留文件**，不发给 AI。右下角闪一下"已复制"，约 1.5 秒后自动消失【我的判断】 |
| **记录** | 带标注的图存进 `shots/`，进补一句小窗（见 4.2），后面和现在一样 |
| **保存…** | 弹出另存为对话框：默认文件夹是上次存的地方，第一次是"图片"文件夹；默认文件名带日期时间；格式 png。存好后截图结束，数据目录里不留文件 |
| **✕** | 什么都不留 |

**按键**

固定的按键【我的判断】：

| 按键 | 作用 |
|---|---|
| Enter，或双击选框 | 主按钮（见下一张表） |
| Tab | 记录；有"没记完的这一条"时是"加到这条" |
| Ctrl+C | 复制 |
| Ctrl+S | 保存… |
| Esc | 取消；有"没记完的这一条"时回到补一句小窗 |

**主按钮随场景变**

| 场景 | 主按钮（Enter） |
|---|---|
| 有"没记完的这一条"（见 4.3） | 加到这条（第 N 张） |
| 主窗口右下角"截一张"、首次引导最后的"试截一张"（这时用户就是想记一条） | 记录 |
| 热键、托盘"截一张" | 按设置"框选后按回车"：复制（默认）或记录（见 4.9） |

- 主按钮是蓝色，其余两个是普通按钮，三个都一直在工具栏上。

**文案跟着改**

快捷键现在默认是复制，不再一按就记录，所以讲快捷键的地方都要改，讲清"回车复制，Tab 记录"：

- 首次引导、应用内"首次安装说明"和 `docs/首次安装说明.md`、README；
- 设置页里快捷键那一行；
- 提醒里讲快捷键的地方。

### 4.2 补一句小窗（主文档 7.2 的改动）

- 输入框上方加一排缩略图。每张左上角标序号，右上角有 ×，点 × 去掉这张。只剩一张时不显示 ×【我的判断】。
- 缩略图后面跟两格：
  - **"＋ 再截一张"**，小字说明"翻到下一屏再截"；
  - **"＋ 加图片…"**，小字说明"也能 Ctrl+V / 拖进来"。点了打开选文件对话框，可以多选。
- 小窗开着时：
  - 按 Ctrl+V，剪贴板里有图片就加进来；
  - 把图片文件拖到小窗上，也加进来。
- **截图开出来的小窗，背后盖着整块屏的变暗定格画面，下面的窗口都看不见。** 所以小窗一失去焦点（用户切到资源管理器或微信去找图），就把变暗背景收起来，小窗本身仍然置顶。这样只有一块屏时，也能从别的窗口把图拖到小窗上。小窗不切走时，样子和现在一样【我的判断】。
- 右上角的"今天第 N 条"后面加上"· N 张图"。
- 回车、Esc、"跳过"的含义不变。已经截好或加好的图都会记进这一条。
- 左下角加一个文字链接"不记了"：不弹确认，直接删掉这条已存的图、作废草稿、关掉小窗，什么都不记，也不发给 AI。没有快捷键，免得误按【我的判断】。
- 满 9 张时，"再截一张"和"加图片"两格变灰。一次加的图超过剩余名额时，多出来的不加，并提示"一条最多 9 张，多出来的没加"。
- 已经打在输入框里的字，在"再截一张"来回的过程中要保留。

### 4.3 "没记完的这一条"和"再截一张"的流程

**"没记完的这一条"是一个独立的状态**【我的判断】。从按 Tab（或从主窗口加图）开始，到补一句小窗里回车、Esc、"跳过"或"不记了"为止，都算"没记完的这一条"，也就是 4.8 里的草稿。"一次截图"是另一个短暂的状态，两者可以同时存在：

- 有"没记完的这一条"时，任何方式开始截图（热键、托盘、主窗口），都进"加到这条"模式（见 4.1 的表）。
  - 补一句小窗开着时按热键：小窗和变暗背景收起，直接进框选，**不再像现在这样只是把小窗叫到前面**。
- "加到这条"模式下，除了"加到这条"以外的出口，都回到补一句小窗，图和字都还在：
  - 复制（Ctrl+C 或点按钮）、保存，照常完成，然后回到小窗；
  - Esc 直接回到小窗。

  这样中途想单纯截个图发给别人，也只需要 Ctrl+C。

"再截一张"的具体步骤：

1. 点"再截一张"：补一句小窗和背后变暗的定格画面一起收起，屏幕恢复可操作。
2. 截图那块屏的顶部居中出现一个小条：`已截 N 张 · 翻到下一屏后按 {热键} 截第 N+1 张`，右边有一个按钮"不截了，去写说明"。
   - 小条不抢焦点，样式参考现有的右下角提示窗。
   - 小条一直留着，直到用户截下一张，或点了"不截了"。
3. 用户自己翻聊天记录，翻好后按热键。从托盘或主窗口点"截一张"也一样。
4. 照常冻结屏幕、出现框选画面，但**上一张的选框已经摆在原来的屏、原来的位置**，工具栏直接出来，主按钮是"加到这条（第 N 张）"：
   - 直接回车，就截同一块区域加进这条；想标注也可以先画；
   - 也可以右键或在框外拖，重新拖一个框。
   - 顶部提示改成：`已截 N 张 · 回车 沿用上次的框，或重新拖一个`。
5. 加好后回到补一句小窗。新图排在最后，输入框里原来的字还在。
6. **在第 4 步按 Esc 不会丢图**：直接回到补一句小窗，图还是原来那几张。只有在补一句小窗里按回车或 Esc，这一条才算结束。
7. 小条上点"不截了，去写说明"：小条消失，补一句小窗回来。

### 4.4 电脑里已有的图片（主窗口"今天"页）

**入口**

- 把图片文件拖到"今天"页上。拖进来时整页盖一层虚线框，写着"松开，用这 N 张图添加一条"。
- 页面有焦点、剪贴板里是图片时，按 Ctrl+V。
- 页面底部新加一个按钮"从图片添加"，点了选文件，可以多选。

**之后**

- 三个入口都弹出同一个补一句小窗，带着这些图。
- 小窗出现在主窗口所在那块屏的中下部，**背后不变暗**，因为没有定格画面。
- 之后可以继续加图、"再截一张"、写一句、记录。
- 已经有一条正在补说明时（补一句小窗开着，或"再截一张"的小条在），从主窗口加的图并进这一条，并把小窗叫到前台【我的判断】。

**顺序**

- 一次拖进或选进的几张，按文件名的自然顺序排（"2" 排在 "10" 前面）。存下来的截图文件名一般带时间，这样排就是先后顺序【我的判断】。
- 每批图排在已有的图后面。
- 顺序不对时，点 × 去掉再按顺序加。

**格式和存储**

- 支持 png、jpg/jpeg、bmp、webp【我的判断】。读不出来的文件跳过，并提示"有 N 个文件不是图片或读不出来，没加"。
- 加进来的图**复制一份**，统一转成 PNG 存进 `shots/` 目录，文件名规则和截图相同（按加入时间）。原文件以后删了、改了，都不影响这条记录。

### 4.5 AI 识别（主文档 7.3–7.5 的改动）

- 发给 AI 的是**画好标注、打好码**的图。打了码的地方 AI 也看不到。
- 一次请求，把所有图按顺序放在同一条用户消息里（多个 `image_url`），最后附上补充说明。
- 提示词里"用户会给你一张电脑屏幕截图"按张数改：
  - 一张时保持原文；
  - 多张时说明"这 N 张截图是同一件事，按顺序看，合起来只写一条"；
  - 不加任何举例。
- 告诉 AI 图上的标注是用户自己加的【我的判断】：
  - 有图时，由代码在提示词末尾追加一句（和"只输出 JSON"那段一样，用户改过完整提示词也照样追加）。
  - 大意是：图上的框、圈、箭头、手写文字、马赛克可能是用户自己加的标注；标注指的地方是重点；不要描述标注本身；不要猜马赛克下面的内容。
  - 不加举例。
- 每张图发送前照旧缩到最长边 ≤ 1600。
- **服务商一次能收的图有上限。** 张数超过这家的上限时，程序把相邻几张**上下拼成一张**，凑到上限以内再发，用户不需要知道。已知的情况：
  - 智谱 glm-4v-plus，据第三方资料一次最多 5 张；
  - Kimi 的 8k 视觉模型上下文小，图一多就超。
  - 每家的具体上限，以及 Kimi 要不要换成更大上下文的视觉模型，见第 5 节。
- 关了"把截图发给 AI"，或选了不能识图的服务商时，照旧只用补充说明生成，和现在一样。
- 识别失败时的"待处理"、重试、手写，都和现在一样。重试时仍然发全部图。
- **超时按张数放宽**：一张图照旧 20 秒；每多一张加 10 秒，最多 60 秒【我的判断】。原因是图多时 20 秒常常不够，超时又会白白重试一次、多花额度。

### 4.6 清单、提示窗、大图

- 清单和历史里，多张图的条目把缩略图叠成一摞，右下角一个小圆标写张数。只有一张图的条目和现在一样。
- 点缩略图打开大图查看器。多张时可以左右翻页（← → 键也行），底部显示"2 / 3"，Esc 关闭。
- 右下角"记好了"提示窗本来就没有缩略图，这次也不加。多图条目在"已记录第 N 条"后面加"· N 张图"【我的判断】。

### 4.7 删除、撤销、清理

- 删除一条、撤销删除、按保留天数清理截图，都要覆盖这条的**所有**图。现有代码大体已按数组处理，要逐处确认，并补上测试。

### 4.8 还没记完的这一条

以前从截图到回车只有几秒，现在"再截一张"的小条可能挂几十分钟，所以没记完的这条也不能丢【我的判断】：

- **草稿**：补一句小窗开着、或小条挂着时，这条的图和输入框里已打的字随时存进数据目录下的一个草稿文件。图本身已经在 `shots/` 里。
- **从托盘退出**：草稿留着，下次启动时和崩溃后一样，自动记成一条（有字带字）并开始识别。效果等于替用户按了回车，只是记下、识别的时机在下次启动。如果退出前就记下，下次启动它只会变成"上次没识别完"的待处理，还得手动重试【我的判断，写计划时改】。
- **崩溃、断电后再启动**：发现草稿，就把它记成一条（有字带字）、排队识别，然后删掉草稿。
- 草稿在记下之前，不算进清单条数和总结。
- **下班提醒**：小条挂着时不弹提醒，这条记完后照常补弹。现有的提醒循环本来就是这样，确认一下就行。
- **日期**：记录归在第一张图截下（或加入）的那一天。

### 4.9 "框选后按回车"设置，和老用户升级

v0.1.0 已经发布，用过的人习惯了"框完直接出补一句"。升级后回车变成复制，按老习惯打字、回车，这条就没记下。另外，有的同事只拿这个软件记工作，平时用别的工具截图。所以【我的判断】：

- **设置**：设置页加一项"框选后按回车"，可选"复制（默认）"和"记录"。
  - 选"记录"时，热键和托盘截图的主按钮变成记录。
  - 各处讲快捷键的文案也跟着这项变："回车复制，Tab 记录"或"回车记录，Ctrl+C 复制"。
- **首次引导**："使用习惯"那一步加这一项，新同事自己选。
- **老用户第一次截图**：升级后第一次截图（设置文件里还没有这一项，就算升级），框选后顶部提示行换成一句醒目的说明，只出现这一次：`现在回车是复制，记一条请按 Tab；想改回回车记录，去设置里改`。

## 5. 留给开发者决定的

- **标注怎么画、怎么出图**。建议在框选窗口里用画布直接按物理像素合成，再把 PNG 交给后端。也可以把标注数据交给 Rust 来画。前提是满足 4.1"出来的图"一节的要求。
- **复制到剪贴板的格式**。要能直接粘进微信、QQ、Word、钉钉。
- **箭头的样式**（实心三角、随粗细变化），以及马赛克格子的具体大小。
- **每家服务商一次最多收几张图**：
  - 先以官方文档和真实调用为准，查不到的按保守值处理；
  - 自定义服务商默认按 9 张处理；如果对方报错说图太多或超长，自动按更小的上限拼图重试一次；
  - Kimi 预设要不要换成 32k 上下文的视觉模型。
- **拼图的具体方式**：竖着拼还是两两拼，拼完后的最大尺寸。原则是聊天文字仍然看得清。
- "再截一张"的小条用新窗口，还是复用现有的提示窗；"已复制"用哪个窗口闪一下。
- 补一句小窗从主窗口打开时（没有定格画面），窗口怎么定位。
- "沿用上次的框"在多屏、不同缩放下怎么存。建议按物理像素存，并记下是哪块屏；上次那块屏没了就不预放。
- 导入大图时要不要先缩小再存。建议原图超过 8000 像素就缩到 8000 以内。

## 6. 验收

**标注与复制**

1. 热键 → 框选 → 回车：剪贴板里是图，能直接粘进微信和 Word。数据目录里没有新文件，没有新条目，没有发 AI 请求。
2. 150% 缩放的屏上画圈、箭头、马赛克后复制：图的尺寸等于框住的物理像素，标注位置和屏幕上看到的一致。
3. 马赛克处是大像素块，看不出原内容。
4. 文字工具能用中文输入法打字；打字时按回车不会把图复制走。
5. Ctrl+Z 能一步步撤销；右键清掉标注、重新框选；Esc 什么都不留。
6. Ctrl+S 能另存为 png，下次默认还是这个文件夹。
7. 上次选的颜色和粗细，下次截图时还在。

**记录**

8. 热键 → 框选 → 画一个圈 → Tab → 回车：记成一条，存下来的图和发给 AI 的图上都有这个圈。
9. 主窗口右下角"截一张" → 框选 → 回车：直接进补一句（主按钮是"记录"）。

**多张图**

10. 截一张 → Tab → "再截一张" → 翻聊天记录 → 热键 → 回车（沿用上次的框）→ 再来一次 → 回车记录：得到**一条**记录，带 3 张图，顺序正确，AI 写出的是一条。
11. 第 10 条中途在框选画面按 Esc：回到补一句小窗，之前的图都在，输入框里的字也在。
12. 小条上点"不截了，去写说明"：补一句小窗回来，图都在。
13. 补一句小窗里：Ctrl+V 粘贴图片、"加图片…"多选文件，都能加图；点 × 能去掉某一张。只有一块屏时，切到资源管理器后变暗背景收起，能把文件拖到小窗上。
14. 往"今天"页拖 3 张图：弹出补一句小窗，带着 3 张图，记录后是一条，顺序按文件名。
15. 加到第 10 张：不加，并有提示。
16. 拖进一个不是图片的文件：跳过并提示，其他图照常加。
17. 选了智谱（或张数上限小的服务商），带 7 张图识别：请求不报"图太多"，能正常出结果。
18. 清单和历史里多图条目显示张数；大图能左右翻页。
19. 删除多图条目再撤销：图都在。按保留天数清理时，多图条目的图都会被清理。

**没记完的这一条**

20. 小条挂着时从托盘退出：再打开软件，这条已经记下并开始识别，图和字都在。
21. 小条挂着时直接结束进程（模拟崩溃）：再打开软件，这条被记成一条，并开始识别。

**两种状态同时存在**

22. 补一句小窗开着时按热键：直接进框选，主按钮是"加到这条"；按 Ctrl+C 复制后回到小窗，图和字都在。
23. 小窗里点"不记了"：没有新条目，`shots/` 里这条的图被删掉，没有发 AI 请求。

**设置和升级**

24. 设置"框选后按回车"改成"记录"后：热键 → 框选 → 回车，直接进补一句；Ctrl+C 仍是复制。
25. 用 v0.1.0 的设置文件启动新版，第一次截图时顶部出现升级说明，第二次不再出现。
26. 识图请求的提示词末尾有关于标注的那句话；用户改过完整提示词时也有。

**整体**

27. 界面文案和提示词里没有任何具体举例。首次引导、安装说明、README、设置页里讲快捷键的地方，都已改成"回车复制、Tab 记录"，并且跟着设置变。
